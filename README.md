# FoldPulse — Every Fold. Every Beat.

A privacy-first iPhone Duo app that counts, records and analyses folds and unfolds. All data stays on the device.

**Current status:** Phase 1 approved. Phase 2 (Brand, UI/UX & Design) deliverables are ready for Founder review. No application code exists yet (only the throwaway `spike/` diagnostic app).
